# PDF Report Format Reference

## Layout & Structure (2-page professional report)

### Page 1 - Main Analysis
1. **Header Section**
   - Title: "Health Intelligence Report" (adapt to "Deepfake Detection Report")
   - Report ID: RPT-2026-1022-603
   - Generated date and patient/file info
   - Download PDF button (top right)

2. **Score Section**
   - Overall Health Score: 67/100 (circular gauge with orange gradient)
   - Status: "Moderate" (adapt to "Likely Deepfake", "Suspicious", etc.)
   - Indicators: 4 flagged biomarkers, 6 within normal range

3. **Clinical Summary**
   - Text description of findings
   - Key metrics highlighted

4. **Biomarker Analysis Table**
   - Columns: Biomarker | Value | Reference | Status | Visual (progress bar)
   - Color-coded status: Green (Normal), Orange (Low/High), Red (Critical)
   - Sections: DIFFERENTIAL COUNT, HEMATOLOGY, RED CELL INDICES
   - Visual progress bars showing value ranges

5. **Risk Assessment**
   - Two cards side-by-side:
     - Left: Hematology Profile (Worsening trend, -95% risk level)
     - Right: Inflammation/Infection (Improving trend, 0% risk level)
   - Each card shows key metrics and trend direction

6. **Biomarker Trend Projection**
   - Line chart showing 5-point timeline (Jan-May)
   - Multiple data series (Hemoglobin, Platelets, MCH)
   - Cyan/purple gradient lines with markers

### Page 2 - Continued Analysis
1. **Biomarker Trend Projection (continued)**
   - Full chart visualization

2. **Personalized Action Plan**
   - Numbered list (1, 2, etc.)
   - Actionable recommendations
   - Professional, clear language

3. **Medical Disclaimer**
   - Warning icon
   - Disclaimer text about AI-generated report

4. **Bottom Button**
   - "Analyze Another" button (cyan/purple gradient)

## Design Elements

### Color Scheme
- Dark background (dark navy/slate)
- Accent colors: Orange, Cyan, Purple, Green, Red
- Text: Light gray/white for readability
- Progress bars: Color-coded (green/orange/red)

### Typography
- Headers: Bold, large font (18-20pt)
- Section titles: Bold, medium font (14-16pt)
- Body text: Regular, small font (10-12pt)
- Monospace for values/numbers

### Visual Elements
- Circular gauge for main score
- Progress bars for metrics
- Line charts for trends
- Color-coded status badges
- Icons for warnings/indicators
- Gradient backgrounds for cards

### Spacing & Layout
- Generous padding around sections
- Clear section dividers
- Table with alternating row backgrounds
- Professional card-based layout
- Consistent alignment and margins
